# Security policy

Safe Agent QA Kit is designed to handle **synthetic or sanitized QA metadata**, not secrets or private production data.

## Do not submit

- API keys, tokens, passwords or private keys;
- customer or employee personal data;
- proprietary source code that you are not authorized to publish;
- production database contents, backups or internal network configuration.

If a security issue in this project could cause secret exposure or unsafe automation, report it privately through the repository owner's GitHub contact channel instead of opening a public issue with sensitive details.

The project intentionally does not auto-merge, deploy or publish changes.
